# Web App Mekânsal Veri Varlıkları (`data/`)

NüfusKaç web harita katmanları için ilçe ve mahalle düzeyinde GeoJSON sınır verilerini barındırır:

* `districts/` — 81 il için il bazlı tam çözünürlüklü resmi ilçe sınırı GeoJSON dosyaları (973 ilçe).
* `mahalleler/` — Tüm Türkiye (`973 / 973` ilçe) için gerçek belediye/MAKS ve OpenStreetMap mahalle sınırları ile doğrulanmış yerleşim koordinatları.
