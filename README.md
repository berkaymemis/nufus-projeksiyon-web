## 🚀 Canlı Dağıtım (1-Click Deployment)

Bu proje sıfır harici Python kütüphane bağımlılığı (**Zero-Dependency**) ile çalışır. Render, Railway, Fly.io veya Docker üzerinde anında çalıştırılabilir.

### Render.com Ücretsiz Dağıtım:
1. GitHub reponuzu Render.com'a bağlayın.
2. 'New Web Service' seçip bu repoyu seçin.
3. Build Command: (Boş bırakın)
4. Start Command: `python server.py --port $PORT --no-browser`
5. Ücretsiz planı seçin ve 'Create Web Service' butonuna tıklayın.

### Yerel Çalıştırma:
```bash
python server.py
```
Tarayıcınızda açın: `http://localhost:8080`
